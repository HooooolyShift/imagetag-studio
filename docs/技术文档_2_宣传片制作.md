## 四、怎么重建（完整可复现步骤）

> 环境：`promo\tools\venv\`（Python 3.12，装了 requests / pillow / numpy / av / miniaudio / imageio-ffmpeg）
> 依赖写盘前先备份：`%LOCALAPPDATA%\ImageTagStudio\library.db`（真实库）**绝不参与**下面的流程。

```powershell
$py = "E:\文档\ChatGPT\图片标签分类\promo\tools\venv\Scripts\python.exe"
$T  = "E:\文档\ChatGPT\图片标签分类\promo\tools"

# 0) BGM：塞壬唱片官网官方 WAV（monster-siren.hypergryph.com）
#    专辑 Endospore → /api/album/2452/detail → 单曲 cid 048713 → /api/song/048713 取 sourceUrl
& $py -u "$T\fetch_bgm.py" endospore endospore      # → promo\audio\BGM_Endospore.wav

# 1) 分镜脚本（唯一事实来源）
notepad "E:\文档\ChatGPT\图片标签分类\promo\tools\promo_plan.py"
& $py -u "$T\promo_plan.py"                          # 打印段落表与总时长

# 2) 素材准备（沙盒库：只在 promo 下建，不碰真实库）
& $py -u "$T\build_demo_library.py"                  # 从 测试图\ 入库 + WD14/CLIP/分级/人脸
& $py -u "$T\manual_tagging.py"                      # 按真实角色名手动打标 + 确认 AI 标签
& $py -u "$T\name_persons.py"                        # 人脸聚类命名

# 3) 界面素材（离屏渲染，2 倍分辨率）
& $py -u "$T\shots_farm.py"                          # → promo\shots\*.png（3840×2160）
& $py -u "$T\motion_farm.py"                         # → promo\motion\（真实操作逐帧）

# 4) 图形层
& $py -u "$T\make_overlays.py"                       # → promo\cards\ + promo\overlays\（卡片/字幕/章节标题）
& $py -u "$T\pad_motion.py"                          # → promo\motion_seq\（帧数补齐到 60fps 对齐时长）

# 5) 音频：BGM 裁到片长 + 淡入淡出（当前版本已去掉音效，ADD_SFX=False）
& $py -u "$T\audio_build.py" build                   # → promo\audio\mix.wav + beats.json

# 6) 时间线 + 预览导出（会按 beats.json 把章节切换吸附到节拍）
& $py -u "$T\build_premiere.py"                      # 建/填序列「宣传片 v5」，铺 A1 音频，导出 H.264 预览

# 7) 出母版 → NVENC 压到 6 Mbps
& $py -u "$T\export_now.py" "promo_master_v5.mov" `
    "D:\PR2024\Adobe Premiere Pro 2024\MediaIO\systempresets\4D584620_504D5846\Apple ProRes 422 HQ.epr"
& $py -u "$T\encode_nvenc.py" "E:\文档\ChatGPT\图片标签分类\promo\premiere\promo_master_v5.mov"

# 8) 封面与发布文案
& $py -u "$T\make_cover.py"                          # → promo\cover\（A 插画版 / B 界面版，1146×717 + 1920×1080）
& $py -u "$T\chapter_times.py"                       # 打印章节时间轴，粘到 promo\B站发布信息.md
```

**关键约束（都是踩过坑总结的）**

1. 时间必须量化到 1/60 秒，否则 Premiere 对齐到帧后，按 ticks 精确查找镜头会失败。
2. 相邻段落不要用同一张素材，静态图一律给慢速推拉；单段 ≤ 12 秒（否则观感是"长时间不动"）。
3. 生成卡片/字幕 PNG 前要先关掉 Premiere——素材被时间线引用时会被锁住，脚本会中途崩，
   出现"字幕只生成了一部分"的假象。
4. 直接改 .epr 里的码率**无效**（实测字节数一样），要码率就 ProRes 母版 + ffmpeg NVENC（`-rc cbr`）。
5. 导出 H.264 的音频容易变 PCM（200 秒白占 57 MB），统一交给 `finalize.py` / `encode_nvenc.py` 换 AAC。
