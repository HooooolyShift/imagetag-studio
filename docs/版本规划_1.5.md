## 一、1.5 内容清单（按提交时间）

### 图库与浏览
- 图库选文件夹时只显示本层图片，不再把子文件夹的带出来
- 库筛选左树子目录层级修复（深层目录正确挂到父级）
- 左树列出磁盘上真实存在的目录（含空文件夹），10 秒缓存 + 新建/改名/删除后即时刷新
- **拖拽修好**：网格补 `ItemIsDragEnabled`、左树 `setAcceptDrops` + DropOnly；`reindex_after_move` 补 `root_id`
  （以前拖进图库看不到）；`K:\pictures` 改回"来源"，只有 `K:\ImageTags` 是图库
- 大图页：滚轮以鼠标位置为中心缩放；新增「适应窗口 / 放大 + / 缩小 −」操作条；左键拖动平移

### 打标与审核
- 审核台词条按"规范名"合并重复（中文名归到对应英文标签，如 芙莉莲 → frieren）
- 扫描词条污染治理：分级别名归一（15禁→R15、18禁→R18、健全/G级→全年龄…），并清理历史脏标签
- 系列图再次打标/审核后自动重算系列标签并刷新文件夹名
- 打码不再拉伸非 1:1 图（KeepAspectRatio + 居中）

### 系列
- 系列排序可视化（缩略图拖动、双击看大图、F2/右键改名），合并与重排共用一套组件
- 拖动系列 = 整组移动；`create_series(use_parent=True)` 可直接用当前文件夹当系列文件夹

### 启动开屏（新增功能）
- 类 Adobe 启动过渡窗口：宽度取屏幕 1/3（520~1100 夹取），图片区高度随图比例自适应（完整显示不裁切），
  Win11 风格 14px 圆角 + 下方独立白底信息条（应用名 / 版本 / 状态），启动分 4 步显示进度条
- 封面：本项目自绘 14 张（NoobAI-XL v1.1，1536×648），伪随机"播放列表"轮换（一轮内不重复）
- 高分屏修复：按设备像素比缩放封面；修正 DPR 换算导致的图片偏移

### 工程与交付
- E/D 双副本：E = 测试版（BETA 角标图标、`beta.flag`、独立便携数据），D = 正式版
- 便携数据模式：程序目录下有 `data/` 就用自己的数据目录（正式版/测试版可同时运行互不干扰）
- 测试版默认扫描来源 = `测试图/`（宣传片会话下载的 112 个文件）
