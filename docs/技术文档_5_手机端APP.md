## 一、目标（未开工）

手机竖屏优先的伴生端：随手浏览/检索 PC 端图库、查看某张图的 tag、按 tag 过滤，
后续可扩展"随手打 tag 进待审核队列"。与平板端共享大部分数据层代码，仅在布局与交互上分开。

## 二、与平板端的差异（约定）

- 平板：大屏分栏、批量操作、审核台体验优先。
- 手机：单列、滑动浏览、检索与查看优先；批量操作简化。
- **数据层（索引读取、tag 解析、分级、中文名映射）两端共用一套代码/规则**，避免出现第二套解析逻辑。

## 三、与 PC 端的数据交换

与《技术文档 4》一致（同一份交换格式，不要在两端各定义一套）：
- 图库文件名即 tag，首位分级（全年龄 / R15 / R18 / R18G）；
- `library.db` 只读复用，或 PC 端导出的 JSON 索引 + 缩略图目录；
- 中文显示优先"中文备注"，词典复用 `app\tag_zh_dict.json` / `app\tag_zh_corrections.json`。

## 四、技术栈（建议，待确认）

Kotlin + Jetpack Compose（Materials 3、动态取色），Room + Coil + SAF/MediaStore；
工程可与平板端合并为一个 Android 项目、两套 UI 模块（推荐），便于共享数据层。
