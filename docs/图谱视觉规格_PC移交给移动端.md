# 图谱视觉规格（PC → 移动端移交，2026-10-07）

> 全部数值都是 PC 端 `app/ui/taxonomy.py` 里的**实际常量**，照着写就能和 PC 长得一样。
> 单位都是**场景像素**（PC 是 QGraphicsScene：1 单位 = 1 px，缩放通过视图变换实现）。
> 移动端可以整体按屏幕缩放（例如 `scale = 屏宽/1600`），但**彼此的比例必须保持一致**。

## 1. 节点（圆形）——尺寸与形状

| 类型 | 直径 | 说明 |
|---|---|---|
| 分类节点 | **118 × 118** | 大圆；有子标签的顶层分类 |
| 有子标签的标签（作品/父标签） | **92 × 92** | 中圆 |
| 普通标签 | **68 × 68** | 小圆 |

- 画的是**正圆**：`d = 直径`，圆心在节点 pos + d/2。
- **圈里画三行字**（全部水平居中）：

  | 行 | 内容 | 字号 | 颜色 | 垂直位置 |
  |---|---|---|---|---|
  | 上 | 分类节点写「分类」；标签写它所属分类名（服装/人物…） | **7.0pt** 常规 | 分类 `#aab6c8`；标签 `#9fb0c6` | `y = d*0.06`，高 `d*0.22`，顶部对齐，超宽省略号 |
  | 中 | 节点名字 | 分类 **9.4pt 粗体**；标签 **8.2pt**（有图片数就粗体） | 分类/有图 `#eef2f8`；无图 `#b9bcc5` | `y = d*0.30`，高 `d*0.52`（热度视图 `d*0.40`），最多两行，放不下加"…" |
  | 下 | 图片数 `N 张`（**仅热度视图**） | **7.4pt 粗体** | `#ffd479` | `y = d*0.72`，高 `d*0.22` |

  名字折行按圆的宽度算：每行能放的汉字数 ≈ `(d - 14) / 字宽`，最少 2 个字符一行。

## 2. 颜色

### 2.1 关系视图（默认）：按"最高层分类的色系"上色 + 层级深浅
- 色系表（14 色循环，按分类顺序取）：
  `#6f8cff #22d3ee #4ade80 #facc15 #fb923c #e879f9 #f472b6 #a3e635 #2dd4bf #f87171 #818cf8 #fbbf24 #34d399 #38bdf8`
- 层级深浅（`depth = level - 1`，level=1 是分类层）：
  - 填充 `fill = base.darker(max(135, 330 - 55*depth))`
  - 描边 `border = base`（depth=0） / `base.lighter(100 + 10*depth)`
  - **分类节点**的填充再暗一档：`fill.darker(115)`
- 兜底色（没用色系时）：分类填充 `#2b3d52` / 描边 `#4a7fc1`；标签填充 `#2a2c33` / 描边 `#4a4e58`；
  有图的标签 `#31343d` / `#5f6572`。
- **没有图的标签用虚线描边**（一眼区分"还没图"和"有图"）。
- 选中描边统一 **`#ffb347`**。

### 2.2 热度视图（切换）
- 色阶（**对数刻度**，按图片数插值）：`0 → #3a3f47`、`1 → #2f6fb0`、`5 → #3fa8c9`、`20 → #5fd07a`、
  `100 → #d8c05a`、`400 → #e08a4a`、`1000+ → #d05050`；标签热度的描边 = `色.darker(150)`。
- **图例**（画在左下角）：标题「热度视图：按图片数」→ 60 段渐变条（对数 0→1000）→ 刻度
  `0 / 10 / 100 / 1000+` → 说明「越红 = 图越多；灰 = 还没有图」；文字颜色 `#8f96a3`。

## 3. 线条与箭头

| 边类型 | 颜色 | 线宽 | 线型 |
|---|---|---|---|
| 分类 → 标签（is_a） | `#5a6270` | **1.6** | 实线 |
| 标签 → 标签（sub_of，从属） | `#3fc1c9` | **2.0** | 实线 |
| 平行关联（parallel） | `#b57cff` | **1.8** | 虚线 |

- 线是**直线**（不是曲线，几千条时省性能）。
- **箭头**画在末端（指向子节点）：三角形，**边长 10.0px**，张角 **±0.42 弧度（≈24°）**，用边色填充。
- 连线在**缩放 < 0.25 时整体隐藏**。

## 4. 缩放、性能阈值与手感

| 项 | 数值 |
|---|---|
| 缩放范围 | **0.1× ~ 5.0×** |
| 滚轮/双指每一格 | ×**1.15**（缩小则 ÷1.15） |
| 文字显示阈值 | 缩放 **≥ 0.55** 才画圈内文字（低于就只画圆） |
| 连线显示阈值 | 缩放 **≥ 0.25** |
| 极远模式 | 缩放 < **0.22**：不画描边、填充 `lighter(125)`；< **0.08**：关抗锯齿直接画方块 |
| 只渲染视野内节点 | 视口外不画（PC 用 QGraphicsView 的可见区域裁剪） |

**弹簧拖拽**：拖动时离原位的距离上限 **240px**（超过就拖不动）；
未到上限时实际位移按 `1 - 0.35 * (dist/240)` 阻尼（**越拖越沉**）；松手弹回原位，
回弹动画 **340ms**（缓动，不是瞬移）。

**搜索定位**：视口平滑移动过去，曲线是**无加速段 → 直接最高速 → 减速到目标**（≈ ease-out）。

## 5. 布局（谁摆在哪）

- **分类节点**：坐标直接用 PC 下发的（`/api/graph` 的 `nodes[].x/y`，PC 库里已有真实坐标）。
- **标签节点**：也由 PC 下发（`app/graph_layout.py` 算的环形分布）：
  第一圈半径 **150**，每往外一圈 **+110**，同一圈相邻节点弧长 ≥ **62px**，
  同一父节点下按图片数从多到少排列，角度从正上方开始顺时针均匀铺。
  没有父分类的标签放到 `半径 1600` 起的最外圈。
- **PC 自己的精细布局**（若要完全一致可参考）：`graph_ring_radius` 默认 **900**（越大越松），
  用自适应扇形面积分配角度；移动端用下发的坐标即可。

## 6. 左栏标签树（和主图联动）

- 层级：分类 → 标签 → 子标签；**默认展开到第 2 层**（分类和它的直接标签），更深层折叠。
- 树节点用**小三角**做折叠/展开；点某个标签 → 主图把该节点居中（带上面的缓动）。
- 树和主图**共用同一份选中状态**：主图选中节点，树上高亮；树上选中，主图高亮。

## 7. 数据来源（不要自己重算）

- `GET /api/graph`：`nodes[].{id,kind,name,zh,category,count,x,y,collapsed,parents}`、
  `edges[].{from,to,relation}`、`heat_scale`。
  `id` 前缀：分类 `g<id>`、标签 `t<id>`；`relation` ∈ `is_a | sub_of | parallel`。
- 颜色：`category` 决定色系（分类名 → 色系序号按分类顺序），`level` 用 `parents` 的层数算。
