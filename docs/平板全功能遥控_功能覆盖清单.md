# 平板「全功能遥控」覆盖清单（PC 功能 × LAN API × 平板现状）

> 结论先行：**PC 端 1.5 的 6 项功能已完成**，但"平板连接后与 PC 完全同步、当遥控器"还**没做完**——
> 缺的不是界面，而是**一批把 PC 能力暴露出去的接口**（下表标 ❌ 的就是）。
> 平板端目前接通的是：设备发现/配对、图库列表、缩略图（单张 + 打包）、原图、标签词典、图谱、审核队列/提交/撤销。

## 交付形态与位数（回答用户提问）

| 端 | 形态 | 位数 | 现状 |
|---|---|---|---|
| PC | `图片标签工坊.exe` + Python 3.10.22 | **64 位（x64，已核实：PE 头 0x8664；Python 64bit）** | ✅ 可运行 |
| 平板 | WebUI（浏览器/PWA） | 与位数无关（跑在浏览器里） | ⚠️ **源码可跑，但还没打成安装包**（无 PWA manifest / APK / 安装包） |
| 平板（若打 APK 外壳） | WebView 壳 | **必须 64 位：ABI 含 `arm64-v8a`**（Google Play 不接受 32 位-only 新应用），`minSdk 26 / targetSdk 34` | ❌ 未做 |
| 手机 | 同上（精简版平板端） | 同上 | ❌ 未开工（用户已说暂不开发） |

相似图 / 区域 / 人脸人物 / 批量删标签 / 清反馈 / 学习包 / 导出 / 清理）。剩下的是**移动端接界面**与
**打包交付**（PWA 或 64 位 APK）。

### 破坏性接口的统一约定

`/api/tags/bulk_delete`、`/api/feedback/clear`、`/api/cleanup` 都是**不可逆或影响面大**的操作，
必须在 body 里带 `confirm: true` 才会执行，否则返回 400 `need_confirm`；
`/api/fs/delete` 走**回收站**（可还原）；路径类参数一律要求落在已登记的库/来源根内（越界 403）。

## 建议的下一批（按"平板最常用"排序）

1. **查重**（用户点名别忘了）：`/api/dupes` + 平板"保留哪张/判为系列/误判反馈"三个按钮。
2. **系列**：`/api/series`（合并、排序可视化、内部页码）。
3. **打标**：`/api/tag/run`（进度走 SSE 推送）+ 平板触发按钮。
4. **写回文件名**：`/api/writeback`（平板审核完能一键落盘）。
5. **目录操作 / 导入**：`/api/fs/*`、`/api/import`（平板上整理图库）。

## 平板端待办（我在会话里已提过，这里再记一份）

- **打包**：做 PWA（可"添加到主屏幕"、离线可用）或 WebView APK；**APK 必须含 `arm64-v8a`**。
- 自检：图谱重叠对数必须为 0（现在它们已做到 219 节点/最小间隙 12px；用真实库 4311 节点也要复核）。
- 时间基准：Python 用 `datetime.now()`；JS 别手工 +8；可用 `/api/ping` 的 `server_time` 校准。
