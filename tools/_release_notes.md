## 图片标签工坊 v1.1（首次发布）

本地离线运行的图片打标与图库管理工具：**WD14 自动打标 + CLIP 自定义标签 + 人脸聚类**。
AI 结果先进待审核队列，你确认后才正式生效（确认/否决都会回馈模型，越用越准）。

**主要功能**

- **自动打标**：WD14（动漫 1 万+ 标签，含角色名）+ CLIP 零样本（你自己的中文标签）+ 人脸聚类（真人）
- **审核台**：逐标签"通过/否决"、可补 AI 漏掉的标签、可框选画面区域告诉模型"这个 tag 对应哪一块"、
  右下角"审核完毕"一键定案（未决标签丢弃且不参与训练）；标签带中文备注显示
- **标签体系图谱**：类型可自定义、多分类、可手动连线、可自动排列；图片只存标签，改层级不影响图片
- **多盘图库**（Steam 式）：每个盘一个专用目录，收录后源文件消失，检索只在图库内
- **系列**：漫画多页合并成一个文件夹，按页码排序、拖动即可改顺序并自动重命名
- **查重**：感知哈希 + CLIP 双检，选一张保留、其余隔离/删除；误报可反馈；可一键"判定为系列"
- **分级识别**：全年龄 / R15 / R18 / R18G，可对 R18 缩略图打码，支持人工专列改判
- **标签写回文件名**：`原名 [tag1 tag2].jpg` 或纯标签命名（可选），手机文件管理器可搜
- **导入**：Lightroom 式导入（选文件夹 → 预览勾选 → 入库 + 可顺手打标）
- **离线**：全程本地推理，不联网、不上传图片

### 怎么安装

**方式一：源码 + 一键脚本（推荐，仓库本体仅约 15MB）**

```powershell
git clone https://github.com/HooooolyShift/imagetag-studio.git
cd imagetag-studio
powershell -ExecutionPolicy Bypass -File tools\setup_env.ps1
```

脚本会自动：创建 conda 环境 → 从国内镜像安装 PyTorch(cu121) / ONNX Runtime / PySide6 等依赖
→ 从 hf-mirror 下载三个模型。**依赖与模型全部来自公开源**：

- 打标：`SmilingWolf/wd-swinv2-tagger-v3`
- 人脸：`immich-app/buffalo_l`
- 自定义标签：`laion/CLIP-ViT-B-32-laion2B-s34B-b79K`

装完双击 `run.cmd` 即可启动。命令行用法见 README（`python -m app.cli ...`）。

**方式二：离线整包（约 4.7GB，目标机器无需联网）**

含全部依赖 wheel 与模型，双击 `图片标签工坊_安装程序.exe` 即可选择路径离线安装；
可用 `tools\build_installer.py` 自行打包，或见仓库说明中的网盘链接。
