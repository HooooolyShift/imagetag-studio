# AI 生图（DLC）用户手册 · 如何接入 ComfyUI

> 这份文档是给**最终用户**看的：装好 DLC 之后，怎么把它连上本机的 ComfyUI，怎么下模型、切换模型、写提示词、出图入库。
> 全程不用碰节点编辑器，也不用改配置文件。

---

## 一、准备什么

| 组件 | 是否必需 | 说明 |
|---|---|---|
| **ComfyUI** | ✅ 必需 | 负责真正出图。可以是任意版本/整合包（秋叶整合包、官方便携版、你自己装的都行） |
| **星卡（NVIDIA GPU）** | ✅ 必需 | 8 GB 显存能跑 SDXL（1024–1536 宽）；Anima 2B 更省显存 |
| **Ollama + 一个本地模型** | ⭕ 可选 | 只有"中文 → 提示词"要用它；**优先用你机器上已有的模型**（见第八节）；没有它，其余功能照常用 |
| 模型文件 | ✅ 必需 | 至少一个底模（见第四节；WAI-illustrious 或 NoobAI-XL 推荐） |

---

## 二、三步接入（推荐路线）

1. 打开主程序 → 菜单「**更多 ▾ → 扩展包（DLC）…**」→ 启用 **AI 生图（DLC）**。
2. 点菜单「**AI 生图（DLC）**」打开窗口。
3. 在「**ComfyUI 接入**」这一栏点 **自动检测**：
   - 它会做两件事：① 在常见位置（`C:\`~`G:\ComfyUI`、`ComfyUI-aki-*`、用户目录、桌面等）找 ComfyUI 安装目录；② 探测 `8188/8189/8000` 端口上是否已有 ComfyUI 在跑。
   - 检测到目录但服务没跑 → 它会问你要不要**直接后台启动**（点"是"即可）。
   - 状态栏显示 `✅ cuda:0 NVIDIA ...` 就说明连上了。

> 如果自动检测没找到：在「安装目录」里手动填 ComfyUI 的目录（**要包含 `main.py` 的那一层**），
> 再点「启动 ComfyUI」或「测试连接」。API 地址默认 `http://127.0.0.1:8188`，端口被占用时改成实际端口。

---

## 三、模型放哪儿

ComfyUI 认的是它自己 `models\` 下的子目录。手动放的话对照这张表：

| 模型类型 | 放到 | 界面上在哪里选 |
|---|---|---|
| SDXL 底模（WAI-illustrious、NoobAI-XL、Animagine …） | `models\checkpoints` | 模型类型 = **SDXL（checkpoints）** → 「底模」下拉 |
| Anima / Flux 这类"单文件扩散模型" | `models\diffusion_models` | 模型类型 = **Anima（diffusion_models）** → 「底模」下拉 |
| Anima 的文本编码器 | `models\text_encoders` | 「Anima 文本编码器」下拉（自动选 qwen_3_06b_base） |
| Anima 的 VAE | `models\vae` | 「Anima VAE」下拉（自动选 qwen_image_vae） |

放完之后在界面点一次「**拉取模型列表**」，新模型就会出现在下拉里（不用重启 ComfyUI）。

## 四、推荐模型与下载

DLC 里带了下载脚本（走 `hf-mirror`，支持断点续传，断电/断网后重跑即可接着下）：

```powershell
# 在 DLC 目录里执行（把 <COMFY> 换成你的 ComfyUI 目录）
python scripts\fetch_model.py "<下载地址>" "<COMFY>\models\checkpoints\WAI-illustrious-SDXL-v17.safetensors"
python scripts\fetch_anima.py          # 一次性下 Anima 三件套（模型 + Qwen3 文本编码器 + Qwen VAE）
```

推荐清单（`models.json` 里也有一份，含体积与 SHA256）：

| 模型 | 体积 | 特点 |
|---|---|---|
| **WAI-illustrious SDXL v17** | 6.5 GB | 线条干净、成图精致，日常首选 |
| **NoobAI-XL v1.1** | 6.6 GB | danbooru/e621 语料，角色还原与构图跟随最好 |
| Animagine XL 4.0 | 6.5 GB | 老牌二次元 SDXL，平涂；风格与上面两个不同 |
| **Anima（aesthetic v1.1）** | 3.9 GB + 1.4 GB | CircleStone × Comfy Org 的 2B 二次元模型，柔和厚涂感；需配套 Qwen3 编码器与 Qwen-Image VAE |

## 五、界面怎么用

### 1. 写提示词：中文直接写
- 在「提示词助手」那一行写中文，例如 `初音未来站在贴满照片的墙前，微笑看镜头，冷色调，半身`。
- 点 **「中文→正+负标签」**：**一次**把正向和负向两组 danbooru 标签都填好（不用切模式）。
- 点 **「只翻服装」**：换装场景专用，只把中文服装描述翻成服装类标签，写进正向。
- **鼠标停在英文 tag 上会弹气泡显示中文**（只有词表里命中的 tag 才显示），方便你确认模型认不认这个词。
- 想自己微调：直接改文本框；「词库」那一行的「规范化提示词」会把中文按主程序词库换成规范英文标签。

### 2. 出图参数（都已按实测固化，默认不用动）
| | SDXL | Anima |
|---|---|---|
| 尺寸 | 1536×648（开屏比例）或 1024×1024 | 768×768 起 |
| 步数 | 60 | 30 |
| CFG | 5.5 | 4.5 |
| 采样 | dpmpp_2m + karras | euler + simple |

切换「模型类型」时这些参数会自动套好。**二段放大和锐化都不用开**（会把平涂模型弄出重影/彩噪）。

### 3. 输出路径
「输出路径」就是用户自己指定的存图目录（DLC 配置项 `output_dir`）。生成完的图会落在那里，
文件名形如 `gen_20261008-143012_123456.png`。

### 4. 批量与入库
- 「张数」直接出多张；种子填 `-1` = 每张不同，填固定数字 = 全部同种子（方便对比）。
- 右侧缩略图双击用系统看图打开。
- 点 **「把生成结果入库（收录到图库）」**：先在主程序里扫描这个输出目录，再点它就能把图收进图库。

## 六、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 状态栏 `❌ 连不上 ComfyUI` | ComfyUI 没启动，或端口不对。点「自动检测」→「启动 ComfyUI」；或手动填目录后启动 |
| 自动检测找不到 ComfyUI | 你的安装位置太特别。手动指定"包含 `main.py` 的那一层"目录即可（整合包常见路径是 `...\ComfyUI-aki-*\ComfyUI-aki-*`） |
| 「拉取模型列表」报错 | API 没连上；先「测试连接」。若刚放进去模型，正常也能拉到（ComfyUI 会即时刷新） |
| 选了模型却报 `ckpt_name not in list` | 这个模型不在 `models\checkpoints` 里，或名字不匹配（界面下拉里的名字就是文件名） |
| Anima 出图报 `clip_name`/`vae_name` 错 | Anima 必须配 `qwen_3_06b_base.safetensors`（text_encoders）与 `qwen_image_vae.safetensors`（vae），用 `scripts\fetch_anima.py` 下全 |
| 「中文→标签」提示 `Ollama ... 11434` | 本机 Ollama 没运行：双击 `D:\LocalAI\start-ollama.cmd`（或按你们的部署方式启动） |
| 生成很慢/爆显存 | 调小尺寸或步数；8 GB 显存下 1536×648 约 40 秒/张，Anima 768×768 约 1 分钟/张 |
| 电脑每天会断电 | 批量出图请分批；模型下载脚本支持断点续传，重跑即可 |

## 七、进阶（可选）

- **局部重绘 / 换装**：DLC 已提供 `workflows/` 模板与固化预设，宿主界面会在后续版本补"画遮罩"的交互；
  在补上之前，可以先在 ComfyUI 原生界面用同样的模型+参数做 inpaint。
- **工作流模板**：`workflows/anima_aesthetic.api.json` 是 Anima 的 API 工作流（占位符 `{{...}}` 由程序替换）；
  `workflows/presets.json` 是我们实测固化的参数集（含双人防克隆预设）。
- **想用浏览器版**：`swarmui_component/` 里保留了 SwarmUI 中文化补丁与扩展源码，属于可选组件，主界面不需要它。

## 八、「中文 → 标签」用的本地模型（**优先接本地已有的，没有再下新的**）

这一条链路**完全离线**：DLC 把中文描述发给本机的 Ollama（`http://127.0.0.1:11434`），
本地模型负责把中文改写成 danbooru 标签，随后再用 DLC 自带的 23 万条词表做校验。
**不联网、不调用任何云端服务**。

### 接入顺序（程序就是这么做的）

1. **先看本机 Ollama 在不在**：在 → 列出已安装模型；
2. **在已有模型里挑最合适的**（不会自己下新的）：
   - 优先级 `qwen3-8b` → `qwen2.5-7b` → `qwen3-14b`/`qwen2.5-14b` → 其它；
   - 都不匹配时，按名字里的参数量（`7b`/`8b`/`14b`…）取最大的那个；
   - 主界面状态栏会显示当前用哪个模型，例如 `…｜提示词模型：qwen3-8b:latest`。
3. **本机一个模型都没有**（或 Ollama 没装）才会提示你处理：
   - 已有 Ollama，只是没模型 → 在命令行 `ollama pull qwen3-8b`（约 4.7 GB，8 GB 显存够用）；
   - 没装 Ollama → 装一个（本机现成的是 `D:\LocalAI`，启动脚本 `D:\LocalAI\start-ollama.cmd`），再拉模型。

### 想指定用哪个模型

在 DLC 的配置项 `ollama_model` 里填模型名（例如 `qwen3-8b:latest`）即可；
**留空 = 自动挑本机最合适的那个**（推荐留空）。

### 显存提示

- 8 GB 显存：`qwen3-8b`（约 4.9 GB）刚好，出图时如果同时跑 SDXL 会显存紧张 —— 建议
  "先翻提示词、再出图"，或者用更小的 `qwen2.5-3b`；
- 模型空闲约 5 分钟会被 Ollama 自动卸载；想立刻让位就 `ollama stop qwen3-8b`。
